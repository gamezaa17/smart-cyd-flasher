CYD Web Flasher

แฟลชไฟล์ .bin ลง ESP32 CYD 2.8" ผ่านเบราว์เซอร์ (Chrome / Edge)

เบราว์เซอร์นี้ไม่รองรับ Web Serial / WebUSB — ใช้ Chrome หรือ Edge (คอมพิวเตอร์ หรือ Android) และเปิดหน้าผ่าน HTTPS · iPhone ใช้ไม่ได้ ให้อัปเดตผ่าน WiFi (OTA) แทน

1. เชื่อมต่อบอร์ด

ยังไม่ได้เชื่อมต่อ

ถ้าเชื่อมต่อไม่ติด: กดปุ่ม BOOT ค้างไว้ แล้วกดเชื่อมต่อ · ถ้าแฟลชพังบ่อยให้ลด baud เหลือ 115200
มือถือ Android: ใช้ WebUSB + สาย OTG แล้วกด "อนุญาต" เมื่อมือถือถามสิทธิ์ USB

3. แฟลช

อัปเดตผ่าน WiFi (ไม่ต้องต่อสาย)

สำหรับบอร์ดที่ลงเฟิร์มแวร์ v1.2.0 ขึ้นไปแล้ว

กำลังตรวจไฟล์...
  1. กดปุ่มด้านบนเพื่อเก็บไฟล์ลงมือถือ (iPhone: เลือก "ดาวน์โหลด" แล้วไฟล์จะอยู่ในแอป Files)
  2. บนจอเกจ: ตั้งค่า → ระบบ → เปิด "ตั้งค่าผ่านเว็บ (Wi-Fi)" รอรีสตาร์ต
  3. มือถือต่อ WiFi OBD-Gauge (รหัสเดียวกับรหัสตั้งค่า ค่าเริ่มต้น obd12345)
  4. เปิด http://192.168.4.1 → ล็อกอิน admin → เลื่อนลงล่างสุด "Firmware update"
  5. เลือกไฟล์ firmware.bin → Upload & update → รอจนเกจรีสตาร์ตเอง
